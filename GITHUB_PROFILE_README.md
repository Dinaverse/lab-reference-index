### 🏗️ Flagship Projects & Research

#### 🧠 [arch-linux-multi-gpu-llm](https://github.com/Dinaverse/arch-linux-multi-gpu-llm)
An optimized Arch Linux deployment engineered to cluster 4 legacy GPUs for local, data-private LLM inference. Focuses on low-level VRAM allocation, custom systemd persistence hooks, and driver stability.

#### 🛡️ [cybersecurity-lab-automation](https://github.com/Dinaverse/cybersecurity-lab-automation)
A modular collection of 40+ custom Python and shell scripts automating local network reconnaissance, proactive host monitoring, and automated forensic log collection.

#### 🌐 [infrastructure-as-code-lab](https://github.com/Dinaverse/infrastructure-as-code-lab)
An infrastructure-as-code sandbox testing declarative deployments, network isolation parameters, and host security baselines within a private home-lab perimeter.
